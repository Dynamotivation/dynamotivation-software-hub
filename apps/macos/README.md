# Dynamotivation Software Hub, macOS frontend

macOS HIG look (macos_ui: translucent sidebar, toolbar, sheets, push buttons) with the Dynamotivation brand gradient and pink accent. Uses `hub_core` and `hub_l10n` only.

```
flutter run -d windows   # design preview on Windows
flutter run -d macos     # on a Mac; enables native window effects
```
