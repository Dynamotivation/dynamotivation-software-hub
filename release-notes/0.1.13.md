Windows now detects installed Dynamotivation applications from the registry, shows their installed versions and available updates, and includes applications absent from the online catalog. The Hub itself is excluded from the software list. Catalog entries are scoped to Windows. Launch now opens the installed application using its registered executable. Installation, updating, and uninstallation remain unavailable until implemented.

The Windows Hub now immediately exits if started with administrator privileges, before initializing Flutter or application services.

Running applications are detected automatically. The fixed-width Launch action offers another instance with Ctrl+click and a confirmed force-close action for all instances of that application.
