Windows now detects installed Dynamotivation applications from the registry, shows their installed versions and available updates, and includes applications absent from the online catalog. The Hub itself is excluded from the software list. Catalog entries are scoped to Windows. Launch now opens the installed application using its registered executable. Software can now be installed and updated from the Hub: the setup downloads with a progress bar in the button, installs silently, and every other action waits until it is done. The ⋯ menu can also install any published version, older or newer, to switch versions. Uninstall sits in the ⋯ menu next to the actions and runs the app's own uninstaller silently. Each install, update and uninstall writes a log to the Hub's Logs folder. Launch now shows a spinner until the app runs instead of a message.

The Windows Hub now immediately exits if started with administrator privileges, before initializing Flutter or application services.

Running applications are detected automatically. The Launch action offers another instance with Ctrl+click and a confirmed force-close action for all instances of that application.

Action buttons resize smoothly as their state changes. Release dates follow the date format set in Windows. Uninstalling the Hub asks whether to keep its logs and settings; the cache is always removed. The Settings page no longer shows the About card, and the ⋯ menu no longer offers Verify files. Buttons, menu items, the version list and the theme selector show the hand cursor when they can be clicked.
