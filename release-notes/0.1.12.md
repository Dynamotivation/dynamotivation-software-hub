- The Hub no longer lists itself as software; its own updates keep working through "Restart to update".
- Far fewer notifications: relaunching or restarting the Hub no longer repeats what you were already told about. Several changes arrive as one summary instead of one notification each.
- While the Hub window is in focus, news appears inside the window instead of as a Windows notification. Notifications show only when the window is in the background or in the tray, and clicking one brings the Hub forward.
- The "Update Hub" button in the title bar now only appears when the Hub actually has an update.
- The tray icon is now the Hub's own icon (the D with the download badge), with a separate variant for dark taskbars.
