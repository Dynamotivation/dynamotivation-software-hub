- Starting the Hub again while it is already running, also when it sits in the tray, now brings the running window forward instead of opening a second copy with its own tray icon.
- Software that was listed before its first release is announced as "New software released: be among the first to try it" when that first release arrives, not as an update. An update is announced only for a newer version; a lower or equal version is never announced.
- News inside the window now appears at the bottom as a notice you can dismiss, instead of pushing the software list and details down. Informational notices use a neutral blue instead of the accent colour, which looked like an error.
